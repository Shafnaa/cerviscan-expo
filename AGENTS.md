# cerviscan-expo — AGENTS.md

## Stack
- **Framework**: Expo SDK 52, Expo Router 4 (file-based routing)
- **Styling**: NativeWind 4 (Tailwind for RN) via `babel-preset-expo` + `nativewind/babel` + `nativewind/metro`
- **UI**: Custom shadcn-style components in `~/components/ui/` — uses `cn()` (clsx + tailwind-merge), `class-variance-authority`, HSL CSS vars in `global.css`
- **Auth**: Custom context (`~/providers/auth-provider.tsx`); tokens persisted via `useStorageState` hook (`expo-secure-store` / `localStorage`)
- **HTTP**: Axios with `publicAxios` and `authAxios` (auto-attaches `Bearer` token via interceptor); both target `EXPO_PUBLIC_BACKEND_URL/api`
- **Package manager**: `bun` (confirmed in `cesconfig.json`, `bun.lockb`)
- **Import alias**: `~/` → root (configured in `tsconfig.json` paths + `app.json` experiments.tsconfigPaths)

## Project layout
```
app/
  _layout.tsx              ← root: ThemeProvider + AuthProvider + Slot
  auth/                    ← login/register (redirects to tabs if authenticated)
  (app)/
    _layout.tsx            ← auth guard (redirects to /auth if unauthenticated)
    (tabs)/                ← 4-tab navigator (Information, Go Scan, Albums, Models)
      index.tsx
      scan/index.tsx
      record/index.tsx
      model/index.tsx
    record/detail/[id]/    ← app-level routes (not nested under tabs)
    model/detail/[id]/
    model/retrain/[id]/
    profile/index.tsx      ← linked from Information tab header
lib/                       ← utilities: constants (NAV_THEME), cn(), useColorScheme, icons
components/                ← ui/ (shadcn-style), auth-form, album-card, model-card, spinner
providers/                 ← auth-provider.tsx
hooks/                     ← use-storage-state.ts
```

## Commands
```sh
bun start              # Expo dev server
bun ios / android / web
bun lint               # ESLint `**/*.{js,jsx,ts,tsx}` + Prettier `**/*.{js,jsx,ts,tsx,json}`
bun format             # ESLint --fix + Prettier --write (same patterns)
bun prebuild           # expo prebuild
```

## Config reference
- **ESLint**: `eslint-config-universe/native` (inline in `package.json`)
- **Prettier**: `prettier.config.js` — singleQuote, bracketSameLine, trailingComma es5, prettier-plugin-tailwindcss
- **Tailwind**: `tailwind.config.js` — `darkMode: 'class'`, content `./app/` + `./components/`, nativewind/preset
- **Babel**: `babel.config.js` — `babel-preset-expo` with `jsxImportSource: 'nativewind'` + `nativewind/babel`
- **Metro**: `metro.config.js` — default Expo config + `withNativeWind({ input: './global.css' })`
- **EAS Build**: `eas.json` — dev (dev client, internal), preview (internal), production (auto-increment)
- **TypeScript**: `strict: true`, `~/` path alias, includes `.expo/types/`
- **Component aliases**: `components.json` — `~/components`, `~/lib`

## Key conventions
- Import alias `~/` over relative paths throughout
- `cn(...)` for conditional className merging
- `useColorScheme()` from `~/lib/useColorScheme` wraps NativeWind's hook
- Auth endpoints use `multipart/form-data` (`FormData`)
- `publicAxios` (unauthenticated) / `authAxios` (auto-attaches Bearer token); both point to `EXPO_PUBLIC_BACKEND_URL/api`
- No test framework configured — do not assume Jest, Vitest, etc.
- `nativewind-env.d.ts` is generated by NativeWind — do not edit
- `expo-env.d.ts` is in `.gitignore` — do not commit

## Environment
- `EXPO_PUBLIC_BACKEND_URL` — required, set in `.env.local` (copy `.env.example`)
- `.gitignore` only ignores `.env`; `.env.local` can still be committed if added — be careful not to check it in
